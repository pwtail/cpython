## Goal

Funny Python (functional python) — диалект Python, реализованный как форк CPython
(кодовая база `cpython-main/`, апстрим — ветка CPython 3.15), который добавляет в язык
функциональные возможности. Синтаксис — **строгий суперсет** Python 3.15;
поведение совпадает всюду, где не задействованы документированные исключения
R5 (неявный return) и R8 (деструктивный match).

## Scope

**Требования**

- **R1. Суперсет.** Любая валидная программа на Python 3.15 без изменений
  разбирается и исполняется на Funny Python. Новый синтаксис не должен менять
  разбор существующих конструкций. Поведение совпадает с CPython везде, где
  не задействованы документированные исключения R5 (неявный return) и R8
  (деструктивный match).
- **R2. Многострочные лямбды.** Анонимная функция с полноценным блоком:
  `def(аргументы):` + suite, разрешённая в statement-позициях (правая часть
  присваивания, `return`, выражение-инструкция). Семантика — обычного `def`:
  замыкания, `yield` превращает её в генератор. Подробности —
  `funny-python-lambda`.
- **R3. Паттерн-деструктуризация.** Инструкция `match pattern = value`, где
  после `match` — любой паттерн, допустимый в `match..case` (mapping,
  sequence, class, or, as, capture, literal, wildcard). При несовпадении
  паттерна — исключение `MatchError`. Подробности — `funny-python-pattern-assign`.
- **R4. Оператор `..`.** Пайплайн: `x` + строка `..f(args)` — значение
  последним позиционным аргументом, цепочка звеньев. Значением может быть
  плоское выражение, def-блок (`def(): 42 ..run()`) или блочное выражение
  (match/if/with/try) — как standalone, так и в RHS присваивания (`res =`,
  значение ниже, звенья на его уровне). Placeholder `..` в аргументах вызова —
  заполняется следующей def-лямбдой или выражением (включая блок-выражения
  R11). Pipe-форма `x ..match:` = `match x:`. Подробности —
  `funny-python-pipeline`.
- **R5. Неявный return.** Последнее выражение тела обычной синхронной функции —
  её возвращаемое значение: `def f(x): x + 1` возвращает `x + 1`. Первое
  документированное исключение из R1 (второе — R8): валидная Python-программа `def f(): g()` в CPython
  возвращает `None`, а здесь — значение `g()`; это наблюдаемо снаружи и требует
  адаптации тестов/кода, полагавшихся на неявный `None`. `...` в позиции
  statement — placeholder, а не значение; `__init__` и `__exit__` исключены.
  Подробности — `funny-python-implicit-return`.
- **R6. `def(...)` в позиции выражения.** Однострочная форма
  `def(параметры): выражение` допустима в произвольных позициях выражений
  (аргументы вызовов и т.п.), а не только в трёх statement-позициях R2.
  Подробности — `funny-python-lambda`.
- **R7. `match` как выражение.** Присваивание `цель = match subject:` + `case`-
  блоки: значение — последнее выражение тела сработавшего кейса; если ничего
  не совпало — `MatchError` (см. R8). Подробности —
  `funny-python-match-expression`.
- **R8. Деструктивный `match`.** Любая форма `match` — исчерпывающий
  диспатч: если ни один кейс не совпал (включая провал guard'а у trailing
  `case _ if cond`), бросается `MatchError`. Второе документированное
  исключение из R1. Trailing unguarded `case _` (или иррефутабельный
  `case x:`) — catch-all: ошибки нет. Подробности —
  `funny-python-destructive-match`.
- **R9. `match def` — функция с кейсами.** Именованная (`match def name(…)`)
  и анонимная (`match def(…)`) формы: определение функции, за которым
  следуют `case`-блоки; вызов как у обычной функции, диспатч по кортежу
  позиционных аргументов. Значение — trailing-выражение сработавшего кейса,
  no-match → `MatchError` (R8). Подробности — `funny-python-match-def`.
- **R10. Блок-аргумент без `(..)`.** `callee def(параметры): suite` на одной
  строке — def-лямбда как аргумент вызова: голая ссылка (`run def(): …`) или
  вызов с `(..)`-hole; позиции — statement и RHS присваивания с одиночной
  целью. Вызов без hole (`f(a) def(): …`) — SyntaxError. Подробности —
  `funny-python-pipeline`.
- **R11. `if`/`with`/`try` как выражения.** В позиции выражения `if`, `with` и
  `try` возвращают значение последнего выражения выбранной ветки (`None`, если
  ветка не заканчивается выражением); `for` и `while` выражениями не
  становятся. Подробности — `funny-python-if-with-try-expr`.

**Вне скоупа (пока)**

- Многострочные лямбды в произвольных позициях выражений: R6 добавляет только
  однострочную форму с телом-выражением.
- Паттерны в остальных target-позициях: `for`, `with ... as`, `except ... as`,
  walrus.
- Обратная совместимость с Python < 3.15.
- Новые фичи языка помимо R2–R11.
- Блок-выражения в произвольных expression-позициях (`return`, аргументы
  вызовов), `async with`- и `except*`-формы — деферы v1, см.
  `funny-python-if-with-try-expr`.
